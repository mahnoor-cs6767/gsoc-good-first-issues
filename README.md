## About this Repository
This repository contains a curated list of beginner‑friendly issues from GSoC 2023 organizations.  
It helps new contributors find easy tasks to start their open‑source journey.

## Languages Covered
- **JavaScript/TypeScript** → Issues from SugarLabs, RocketChat, Zulip, Element Web, Joplin, Jitsi, Submitty, Joomla, Oppia  
- **C++** → Issues from Inkscape  
- **Python** → Issues from Oppia
